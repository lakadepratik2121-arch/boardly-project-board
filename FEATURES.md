# Boardly – Project Features

## 1. Overview
Boardly is a real-time collaborative project management platform that helps teams organize tasks, manage deadlines and work together efficiently.

## 2. Problem Statement
Teams and students often struggle to organize tasks, assign responsibilities and track project progress. Boardly provides a centralized workspace for managing projects and collaborating with team members.

## 3. User Roles

### Board Owner
- Create project boards.
- Invite team members.
- Manage board settings.
- Manage board membership.

### Board Member
- View assigned boards.
- Create and update task cards.
- Set task deadlines.
- Comment on tasks.
- Track project activities.

## 4. MVP Features

1. User signup and login.
2. Create project boards.
3. Invite team members.
4. Create lists within boards.
5. Create cards with titles and descriptions.
6. Set card due dates.
7. Assign cards to team members.
8. Add comments to cards.
9. Maintain an activity log.
10. Implement board-level permissions.

## 5. Heavy Feature
Drag-and-drop functionality with persistent card ordering and real-time synchronization using Socket.io.

## 6. Technology Stack
- Frontend: React.js
- Styling: Tailwind CSS
- Backend: Node.js
- API: Express.js
- Database: MongoDB
- ODM: Mongoose
- Authentication: JWT and bcrypt
- Real-time communication: Socket.io
- API testing: Postman
- Version control: Git and GitHub

## 7. Future Enhancements
- Notifications.
- File attachments.
- Calendar view.
- Advanced analytics.
- Dark mode.

## 8. Expected Outcome
A responsive and secure project management application with collaborative boards, task management and real-time updates.
